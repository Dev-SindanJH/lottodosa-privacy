데이터 삭제 요청 안내

앱 이름: 로또도사 · 개발자: 로또도사 개발자 · 최종 수정일: 2026년 8월 27일

로또도사는 회원가입·로그인 기능이 없으며, 개발자가 운영하는 서버에 이용자의 데이터를 저장하지 않습니다. 앱에서 생성·저장된 모든 데이터는 이용자의 기기 안에만 보관되므로, 아래 방법으로 이용자가 직접 즉시 완전히 삭제할 수 있습니다.

방법 1. 앱 안에서 저장한 번호 삭제하기

  1. 로또도사 앱을 실행합니다.
  2. 저장한 번호 목록 화면으로 이동합니다.
  3. 삭제할 번호 조합의 삭제 버튼을 눌러 개별 삭제합니다.

방법 2. 앱 데이터 전체 삭제하기 (권장)

  1. 기기의 설정을 엽니다.
  2. 애플리케이션(또는 앱) → 로또도사를 선택합니다.
  3. 저장공간 → 데이터 삭제(저장공간 지우기)를 누릅니다.
  4. 저장된 번호, 화면 설정, 광고 노출 기록이 모두 즉시 영구 삭제됩니다.
  5. 기기에 저장돼 있던 인앱결제 혜택 기록도 함께 지워지지만, 구매 자체가 취소되는 것은 아닙니다. 앱의 스토어 화면에서 "구매 복원"을 누르면 남은 혜택을 다시 불러올 수 있습니다.

방법 3. 앱 삭제

앱을 삭제(제거)하면 앱이 기기에 저장한 모든 데이터가 함께 영구 삭제됩니다. 개발자가 별도로 보관하는 사본은 존재하지 않습니다.

방법 4. 광고 식별자 삭제

광고 제공을 위해 사용되는 광고 ID는 기기 운영체제가 관리합니다. 아래 경로에서 초기화하거나 삭제할 수 있습니다.

  • Android: 설정 → Google → 광고 → "광고 ID 삭제" 또는 "광고 ID 재설정"
  • iOS: 설정 → 개인정보 보호 및 보안 → 추적 → 앱이 추적을 요청하도록 허용 해제
